# Theme-Builder

Im Theme-Builder (**Dashboard → Themes**) gestaltest du dein eigenes Aussehen und nutzt es für mehrere Alben.

![Theme-Builder](/screenshots/de/theme-builder.png)

## Was du ändern kannst

| Teil | Optionen |
|---|---|
| **Name** | Deutscher und englischer Name |
| **Anlass** | Einer der 13 Anlässe (für Gruppierung und Icons) |
| **Farben** | Hintergrund, Fläche, Text, gedämpfter Text, Akzent und Textfarbe auf Akzentflächen. Der Builder warnt bei schlechtem Kontrast |
| **Schriften** | Überschrift- und Fließtextschrift aus dem mitgelieferten Set: Inter, Nunito, Quicksand, Fredoka, Lora, Merriweather, Playfair Display, Cormorant Garamond, Dancing Script, Great Vibes, Caveat |
| **Muster** | none, dots, confetti, hearts, stars, snow, leaves, eggs, waves, balloons, rings, fireworks, grid – mit einstellbarer Deckkraft |
| **Rahmen** | keiner, abgerundet, Polaroid, Büttenrand, Briefmarke, Gold, weicher Schatten |
| **Ornament** | Ein Emoji, das um den Albumtitel angezeigt wird (optional) |
| **Reaktionen** | 1 bis 6 Reaktionen, jeweils mit Emoji und deutschem/englischem Label |

Eine Live-Vorschau zeigt Cover und Fotoraster, während du bearbeitest.

::: tip Alle Schriften sind selbst gehostet
Die Schriften sind in Wayfare enthalten – Browser deiner Besucher kontaktieren weder Google Fonts noch sonstige Dritte.
:::

## Von einem bestehenden Theme ausgehen

Wähle bei einem eingebauten Theme **Duplizieren**, um es als Basis zu nutzen. Das neue Theme merkt sich, woher es stammt.

## Export und Import

Themes lassen sich als kleine JSON-Datei exportieren und auf einer anderen Wayfare-Instanz importieren – praktisch, um ein Design mit Freunden zu teilen.

## Veröffentlichen (Admins)

Eigene Themes sind privat für ihre Besitzer. Ein Admin kann ein Theme **instanzweit veröffentlichen**, sodass alle Owner es auswählen können.

## Löschen

Löschst du ein Theme, das in Gebrauch ist, fallen Alben, die es nutzen, auf *Neutral* zurück.
