# Themes

Ein Theme steuert Farben, Schriften, Hintergrundmuster, Fotorahmen, ein dekoratives Emoji-Ornament und die **Reaktionen**, die Gäste nutzen können. Wayfare liefert **13 eingebaute Themes** mit, eines pro Anlass.

### Das Gedenken-Theme

Das Theme „Trauer & Gedenken“ ist bewusst respektvoll: kein Muster, kein Rahmen und keine lachenden oder Party-Emojis. Gäste können nur eine **Kerze 🕯️**, ein **weißes Herz 🤍**, eine **Taube 🕊️** oder eine **Rose 🌹** hinterlassen. Bei Gedenk-Alben empfehlen wir, Kommentare auf *erst freigeben* oder *aus* zu stellen – siehe [Moderation](./moderation).

## Ein Theme wählen

Wähle das Theme beim Erstellen oder später in den Album-Einstellungen. Die Vorschau aktualisiert sich sofort. Bereits abgegebene Reaktionen bleiben gespeichert; wechselst du zu einem Theme mit anderen Reaktionen, werden nur die Reaktionen des neuen Themes angezeigt.

## Eigene Themes

Du kannst eigene Themes erstellen oder von einem eingebauten ableiten: siehe [Theme-Builder](./theme-builder). Admins können eigene Themes für alle auf der Instanz veröffentlichen.

Gelöschte oder unbekannte Themes fallen auf das Theme *Neutral* zurück, damit Alben nie kaputtgehen.
