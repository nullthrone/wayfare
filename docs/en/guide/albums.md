# Albums

## Create an album

On the dashboard choose **New album**, enter a title, pick a **theme** and optionally write a **greeting** — this text appears on the album cover and on the back of the printed postcard.

![Create album](/screenshots/en/album-new.png)

New albums start as a **draft**: only you (and admins) can see them. Add photos, check how it looks and publish when you are ready.

## Album settings

Open an album and go to **Settings**.

![Album settings](/screenshots/en/album-settings.png)

| Setting | Description |
|---|---|
| **Title / greeting** | Shown on the cover, in print exports and the browser tab |
| **Status** | *Draft* (only you) or *Published* (reachable with link/QR) |
| **Theme** | Colours, fonts, pattern, photo frame and reactions — see [Themes](./themes) |
| **Access** | *Link* (anyone with the link) or *Password* — see [Sharing](./sharing) |
| **Expiry date** | After this date the album shows "expired" to guests. Empty = never |
| **Downloads** | Allow guests to download originals, or protect photos — see [Download protection](./download-protection) |
| **Comments** | *Off*, *publish immediately* or *approve first* — see [Moderation](./moderation) |
| **Reactions** | Turn the theme's emoji reactions on or off |
| **Guest uploads** | Let signed-in guests contribute photos (always approved by you first) and set a limit per guest |
| **Notifications** | *Off*, *instant* e-mail or *daily digest* — see [Notifications](./notifications-stats) |

## Publish

Set the status to **Published**. From now on everyone with the link or QR code can open the album (and enter the password, if you set one). Switch back to *Draft* at any time to hide it again.

## Delete an album

At the bottom of the settings you can delete the album. This permanently removes all its photos, comments, reactions and reports. Printed QR codes will then lead to a "not found" page.
