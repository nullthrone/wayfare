# Themes

A theme controls colours, fonts, background pattern, photo frame, a decorative emoji ornament and the **reactions** guests can use. Wayfare ships **13 built-in themes**, one per occasion.

Each theme offers 1 to 6 reactions; every reaction has a German and an English label. Guests only see the reactions of the album's theme.

### Memorial theme

The memorial theme is deliberately respectful: no confetti or celebratory emojis. Guests can only leave a **candle 🕯️**, a **white heart 🤍**, a **dove 🕊️** or a **rose 🌹**. For memorial albums we recommend turning comments to *approve first* or *off* — see [Moderation](./moderation).

## Choosing a theme

Pick a theme when creating an album or later in the album settings. The preview updates immediately. Reactions already given stay stored; if you switch to a theme with different reactions, only the reactions belonging to the new theme are shown.

## Your own themes

You can create custom themes or derive them from a built-in one: see [Theme builder](./theme-builder). Admins can publish custom themes for everybody on the instance.

Themes that are deleted or unknown fall back to the *Neutral* theme, so albums never break.
